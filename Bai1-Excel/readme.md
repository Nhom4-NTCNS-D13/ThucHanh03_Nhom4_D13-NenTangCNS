# Bài 1 - Microsoft Excel

File: `Buoi03_Bai_1.xlsx`

## Các sheet

| Sheet | Nội dung |
|---|---|
| Tổng hợp điểm | Bảng chính, 14 sinh viên, công thức câu a đến d, đã Freeze Panes tại D7 |
| Điểm thực hành các buổi | Dữ liệu nguồn 3 buổi thực hành |
| Điểm bài tập lớn | Dữ liệu nguồn bài tập lớn |
| Điểm lý thuyết | Dữ liệu nguồn điểm lý thuyết |
| Các bảng tham chiếu & Thống kê | Bảng quy đổi, bảng chuyên cần, danh sách SV, thống kê, biểu đồ tròn |
| Sinh viên điểm < 7 | Kết quả Advanced Filter, 11 sinh viên |
| Sinh viên điểm >= 7 | Kết quả Advanced Filter, 1 sinh viên |

Vùng tiêu chuẩn của Advanced Filter đặt tại cột M và N của sheet Tổng hợp điểm.
